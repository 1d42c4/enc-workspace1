# Verification

Run the Rust tests with `cargo test --locked --workspace -- --test-threads=2`.
Each numbered app includes `support/tests/app_tests.rs`, using its actual cipher,
credential mode and compiled CLI. Unit tests in solid-core cover the shared
framing, KDFs, permissions and publication. Test builds optimize cryptography so
the production-strength Argon2 profile remains practical; no weaker test KDF is used.

Fixtures in `fixtures/aN.hex` were generated by `reference.py` using Python
cryptography/OpenSSL and PyNaCl/libsodium. They have deliberately public test
passwords, keys and fixed salts. They are not user secrets. The fixtures test the
whole envelope and credential derivation, not just the underlying cipher.

To independently verify compiled release executables in both directions:

```console
python -m venv .venv
# Activate the virtual environment for your shell.
python -m pip install -r verification/requirements.txt
cargo build --locked --release --workspace --bins
python verification/reference.py --binary-dir target/release --large
```

`--large` additionally verifies 256 MiB + 1 byte files for all six key-file apps,
crossing the real segment-rekey boundary. The verifier uses temporary files and
bounded memory; it checks Rust encryption with the reference decryptor and reference
encryption with the Rust decryptor. Output: `independent-results.json`.
`--fixtures` regenerates fixed known public fixtures and must not be used to
silently replace fixtures to make a format change pass. It does not test Rust by itself.

Published primitive vectors are from NIST GCM examples/CAVP, RFC 8439 section 2.8.2,
the XChaCha draft appendix, RFC 8452 appendix C, RFC 5869 case 1, and RFC 9106.
The Rust and independent test source retains URLs in root SECURITY.md.

See root AUDIT.md and recorded JSON results for executed checks and limitations.
